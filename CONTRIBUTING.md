# Contributing ideas

UNSPOKEN MINDS SAFEspace welcomes ideas, product feedback, research leads,
accessibility suggestions, and safety observations.

Before opening an Issue or Discussion, read `IP_POLICY.md` and `LICENSE`.

## What to submit

- A clear description of the problem or opportunity.
- Your proposed idea and who it would help.
- Relevant evidence, links, or references that you are permitted to share.

Do not post crisis information, private health information, credentials,
personal data, or confidential material in public spaces.

## Code changes

This project does not accept unsolicited pull requests. Contact the owner and
receive written approval before preparing any code change. Approved code
contributions require a signed Contributor Assignment Agreement before review
or merge.

Submitting feedback does not grant contributor status, approval rights,
ownership, or a right to use future implementations commercially.
